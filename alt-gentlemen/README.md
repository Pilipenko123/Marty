# 🎩 Alt-Джентельмены

Приватный чат для своих: регистрация по имени и паролю прямо в браузере (ПК и телефон),
вся история хранится у вас, сообщения шифруются сквозным шифрованием, есть поиск по всей
переписке, аватары, шкала заполнения памяти и архивация истории.

---

## 1. Как запустить (5 минут)

### Шаг 1. Установите Node.js
Скачайте LTS-версию с [nodejs.org](https://nodejs.org) и установите (Windows / macOS / Linux).
Проверка — в терминале (Windows: «Командная строка» или PowerShell):

```bash
node -v
```
Должна появиться версия, например `v22.x`. Нужна версия **18 или новее**.

### Шаг 2. Запустите чат
В терминале перейдите в папку с чатом и запустите сервер:

```bash
cd путь/к/репозиторию/alt-gentlemen
node server.js
```

Увидите:

```
  ╔══════════════════════════════════════════════╗
  ║           A L T - Д Ж Е Н Т Е Л Ь М Е Н Ы    ║
  ╚══════════════════════════════════════════════╝

  Чат запущен. Открывайте в браузере:
    • на этом компьютере: http://localhost:8080
    • в этой Wi-Fi сети:  http://192.168.x.x:8080
```

> Никаких `npm install` не нужно — внешних библиотек нет.

### Шаг 3. Основайте клуб (только один раз)
Откройте **http://localhost:8080**. При первом запуске появится экран «Основать клуб»:

1. **Ваше имя** и **ваш пароль** — вы становитесь администратором.
2. **Кодовая фраза чата** — общий «ключ от двери». Её придумываете вы и передаёте друзьям
   (лично, голосом, в другом мессенджере). Без неё в чат не зарегистрироваться, а история
   не расшифровывается.

Готово. Чат работает, пока запущен `node server.js`. Остановить — `Ctrl + C` в терминале.

### Шаг 4. Пригласите друзей
Друг открывает адрес чата → вкладка **«Регистрация»** → вводит:
кодовую фразу (от вас) + своё имя + свой личный пароль. Всё, он в клубе.
У каждого — **свой** пароль; кодовая фраза нужна только для первого входа с устройства.

## 2. Как открыть чат с телефона

**Вариант А — тот же Wi-Fi (быстро).**
Браузеры разрешают шифрование только на `https://` или на `localhost`, поэтому для телефона
запустите сервер с HTTPS (нужен `openssl`, он есть в macOS/Linux, в Windows — в составе Git):

```bash
HTTPS=1 node server.js            # macOS / Linux
set HTTPS=1 && node server.js     # Windows CMD
$env:HTTPS=1; node server.js      # Windows PowerShell
```

Затем на телефоне откройте `https://192.168.x.x:8080` (адрес показан при запуске) и один раз
подтвердите «Всё равно перейти» — сертификат самоподписанный, соединение при этом шифруется.

**Вариант Б — доступ из любой точки мира.** Поднимите сервер на дешёвом VPS и поставьте перед
ним [Caddy](https://caddyserver.com) — он сам получит бесплатный сертификат:

```
chat.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

**Вариант В — временный туннель** (`cloudflared tunnel --url http://localhost:8080`,
`ngrok http 8080`): даёт https-ссылку, пока запущен туннель.

## 3. Что умеет чат

| Возможность | Где |
|---|---|
| Регистрация «имя + пароль» | экран входа, вкладка «Регистрация» |
| Смена своего имени и пароля | «Профиль» в левой колонке |
| Аватар (любая картинка, обрезается в квадрат) | «Профиль» → «Загрузить аватар» |
| Картинки в сообщениях | скрепка 📎 слева от поля ввода |
| Поиск по всей истории | поле «Поиск…» вверху: несколько слов = все должны встретиться; клик по результату переносит к сообщению |
| Шкала заполнения памяти | левая колонка: проценты, мегабайты, число сообщений; при 80 % появляется предупреждение |
| Архив истории | «Сохранить архив»: читаемый HTML (со своим поиском), JSON или зашифрованная выгрузка |
| Архивировать и начать новый чат | «Управление» → «Заархивировать историю и начать новую» (только админ) |
| Удаление сообщений | своё — любой участник, любое — администратор |
| Управление участниками | «Управление»: назначить/снять администратора, исключить |
| Смена кодовой фразы | «Управление» → «Обновить фразу» (старая перестаёт пускать новых) |
| Онлайн-индикатор | зелёная точка рядом с именем |

Кнопка «Управление» видна только администраторам. Вы можете назначить админом кого-то ещё.

## 4. Память и архивы

* Лимит по умолчанию — **25 МБ** (это десятки тысяч текстовых сообщений; картинки «съедают» больше).
* Шкала в левой колонке показывает, сколько занято. На 80 % появляется подсказка архивировать.
* При достижении лимита новые сообщения не отправляются, пока историю не заархивируют.
* **Архивация** (админ → «Управление»): история сохраняется в файл на сервере
  (`alt-gentlemen/data/archives/archive-….json`), браузер сразу скачивает копию, а чат начинается с чистого листа.
  Все участники, пароли и аватары остаются на месте.
* Перед архивацией полезно нажать «Сохранить архив» → **«Читаемая копия (HTML)»**: получится
  один файл, который открывается в любом браузере, без чата и без паролей, и умеет искать по тексту.
* Изменить лимит:

```bash
STORAGE_LIMIT=104857600 node server.js   # 100 МБ
PORT=9000 node server.js                 # другой порт
```

## 5. Безопасность

* Сообщения, вложения и аватары шифруются **в браузере** (AES-256-GCM) ключом комнаты.
  На сервер и на диск попадают только зашифрованные блобы — в файле `data/db.json`
  прочитать переписку нельзя даже с полным доступом к серверу.
* Ключ комнаты хранится дважды в «завёрнутом» виде: под вашей кодовой фразой (для приглашения
  новых участников) и под личным паролем каждого участника. Сам ключ сервер не видит никогда.
* Пароли на сервер не отправляются: из пароля в браузере выводится отдельное проверочное
  значение (PBKDF2-SHA256, 150 000 итераций), сервер хранит только его scrypt-хеш.
* Подбор паролей и кодовой фразы ограничен: 25 попыток за 10 минут с одного адреса.
* Смена пароля перешифровывает ваш экземпляр ключа и закрывает сессии на других устройствах.
* **Пароль восстановить невозможно** — это цена шифрования. Если друг забыл пароль:
  «Управление» → исключить его → он регистрируется заново по кодовой фразе (история сохранится).
* Резервная копия — просто скопируйте папку `alt-gentlemen/data`.
* Папка `data/` не попадает в Git (см. `.gitignore`).

## 6. Чтобы чат работал постоянно

**Linux (systemd), файл `/etc/systemd/system/altg.service`:**

```ini
[Unit]
Description=Alt-Dzhentelmeny chat
After=network.target

[Service]
WorkingDirectory=/home/user/Marty/alt-gentlemen
ExecStart=/usr/bin/node server.js
Environment=PORT=8080
Restart=always
User=user

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now altg
```

**Проще:** `npm i -g pm2 && pm2 start server.js --name altg && pm2 save`.

## 7. Проверка работоспособности

При запущенном сервере можно прогнать самотест API и шифрования:

```bash
node test-flow.mjs
```

Он создаёт админа, друга, отправляет сообщения, проверяет, что на сервере нет открытого
текста, что работают поиск, смена пароля/имени, права и архивация.
Запускать лучше на пустой базе (`data/db.json` отсутствует).

## 8. Что где лежит

```
alt-gentlemen/
├── server.js          сервер (Node.js, без зависимостей)
├── public/
│   ├── index.html     экраны: настройка, вход, чат
│   ├── styles.css     оформление (графит + латунь)
│   └── app.js         клиент: шифрование, синхронизация, поиск, архивы

└── test-flow.mjs      самопроверка
```
