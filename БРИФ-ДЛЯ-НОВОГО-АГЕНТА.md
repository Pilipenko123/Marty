   где менялся `public/`. Сейчас **`sega-static-v101`**. Литерал кэша продублирован

7. **Обратная совместимость базы.** Старые записи читаются новой версией:

### Что сделано в pkg3-108

1. **Клавиатура не прячется после отправки.** Кнопка «отправить» больше не
   забирает фокус у поля ввода (`noFocusSteal`: отмена `mousedown`), а само
   поле после отправки возвращает фокус (`keepKeyboard` в `send()`). Убирает
   клавиатуру только касание свободного места в ленте (`hideKeyboard()` в
   `handleMsgClick`).
2. **Шторка списка чатов на телефоне** закрывается не только крестиком:
   появилось затемнение `#rail-scrim` (касание правее шторки = закрыть) и
   смахивание пальцем влево (`railSwipe()`); открытие/закрытие собраны в
   `openRail()` / `closeRail()` — прямых `classList`-переключений больше нет.
3. **Плашка под сообщением не прячется за полем ввода**: `keepMsgVisible(el)`
   поднимает ленту так, чтобы низ сообщения вместе с плашкой был виден
   (вызывается при показе плашки, при касании по медиа и при выборе реакции на
   телефоне).
4. **Смайлы всегда загружаются.** Причины были две: (а) в наборах реакций
   стояли ПУСТЫЕ строки (`RX_SET`, `MS_RX_SET`) — пустые кнопки; (б) картинки
   шли с чужого CDN, а имена файлов строились с ошибкой (`❤️` → `2764-fe0f.svg`,
   такого файла не существует — правильный `2764.svg`). Сделано:
   - все 50 смайлов меню и наборов реакций лежат ВНУТРИ программы
     (`public/img/emoji/<код>.svg`, Twemoji 14.0.2, CC-BY, ~200 КБ);
   - редкий смайл из письма отдаёт наш сервер: новый `lib/emoji.js` + открытый
     маршрут `GET /api/emoji/<код>.svg` (копия в памяти, потолок 700 картинок,
     строгий образец кода — ни путей, ни чужих адресов);
   - цепочка отказов на клиенте: наш сервер → чужой CDN → системный значок
     (`segaEmoFail`). Пустой кнопки не бывает ни при какой сети;
   - правильные имена файлов: `twCode()` (у одиночного знака FE0F в имени
     файла не пишется, внутри склейки ZWJ — пишется).
5. **Порядок в тестах:** номер выпуска читается из кода (`test/build.mjs`),
   новые наборы `test/emoji108.mjs` (29 ✓) и `test/ui108.mjs` (41 ✓).
6. Кэш `sega-static-v101` (имена v99/v100 заняты откаченными 106/107 —
   специально взято «с запасом», чтобы устройства точно выкинули старые кэши).

1. **Нет `ps`, `pkill`, `curl`, `unzip`, `patch`, `hexdump`.** Архивы — python
   `zipfile`, патчи — `git apply`, HTTP — python `urllib` / node `fetch`.
2. **Внешняя сеть ограничена**: открыты `github.com`, `codeload.github.com`,
   `api.github.com`, `registry.npmjs.org`, `pypi.org`, `files.pythonhosted.org`.
   **Не открыты** `cdn.jsdelivr.net`, `cdn.radio-t.com`, `mp3d.jamendo.com`,
   `yapfiles.ru`. Поэтому: картинки смайлов в песочнице берутся из папки
   программы (с pkg3-108 это не проблема), а «живые» проверки чужих сайтов
   делает только VPS.
3. **Порт 9000 занят службой песочницы** (PID 1). Тесты поднимают сервер на
   случайном порту. `EADDRINUSE` даёт «ЕСТЬ ПРОВАЛЫ» без единой ✗ — перезапуск.
4. **ГРАБЛЯ СБОРКИ:** после `npm prune --omit=dev` остаются только рантайм-
   зависимости, `jsdom` пропадает, `dom42`-подобные наборы молча пропускаются
   (в логе «пропущено (не установлен jsdom)»), цепочка всё равно зелёная —
   ЛОЖНОЕ ЗЕЛЁНОЕ. Перед каждым `npm test` — полный `npm install`; ориентир —
   строка «Разметка pkg3-44: 502 ✓».
5. **Песочница может прийти пустой или сброситься посреди сеанса.** Лечение:
   восстановить свежим клоном (`git clone https://github.com/Pilipenko123/Marty`)
   и продолжить. Не паниковать и не переспрашивать владельца.
6. **`node_modules` в репозиторий не попадает** (добавлено в
   `sega-chat/.gitignore` в pkg3-108).
7. **Суточный лимит «одна ссылка в сутки»** мешает тестам со слиянием: есть
   `INVITE_COOLDOWN_MS` (env) — в опытах ставь 0.
8. **Свои тестовые серверы в новых наборах держат event loop** (живой сервер +
   игрушечные сайты): в конце набора ОБЯЗАН быть `process.exit(bad?1:0)`.
9. **`gh` авторизован** — для запросов к API GitHub используй `gh api`
   (лимит выше, чем у анонимных 60 запросов в час).

- Хардкодить номер выпуска в тестах (кроме парных литералов кэша).
- Выпускать без полного `npm test` (зелёный, код возврата 0).
- Пушить в `main` напрямую, менять и переименовывать ветку сессии.
- Трогать PID 1 в песочнице и занимать порт 9000.
- Начинать «Папку с ПК», «запасной сервер», «Поторопить», блокировку старой
  учётки, чистку bonds, закрытие старых пул-реквестов #1/#3 без прямой команды.
- Писать владельцу простынями кода и английскими терминами.
- Удалять данные на сервере (удаление участника — только существующим
  админ-маршрутом, покрытым тестами).
- Класть в зеркало секреты (ключи Яндекса, Jamendo, токены) — только
  `/opt/sega/keys/` на VPS и в зашифрованном виде в базе.
- Ставить на VPS до зелёной сверки: установщик берёт код из зеркала, поэтому
  сначала пул-реквест слит, потом `setup.sh`.

## 13. ПРИЛОЖЕНИЕ: ГЛАВНЫЕ ИНВАРИАНТЫ МЕССЕНДЖЕРА (чтобы не сломать случайно)

- Кто написал в dm хотя бы письмо — навсегда в `chat.savedBy`; «несохранённый» =
  ещё не решил (инвариант раздела «Новые»).
- Живой отсчёт «Новых» важнее отметки «открывал»; меню «Сделать прочитанными?»
  помечает ВСЁ в чате, включая ветки.
- Ключ группы: история на устройстве (`sega.oldKeys.v1`), поколения `ep`,
  автообмен прежними ключами, перевыпуск с кулдауном 1 ч; права — создателю и
  админу.
- Слияние учёток = ТОЛЬКО внешность (`user.displayAs`); авторство и ключи
  прежние; цепочки псевдонимов запрещены. Имя участника единственно.
- Пуш: свободный текст на сервер не приходит — подпись из `NOTIFY_BODIES`;
  «смотрю на доску» watchNow TTL 12 с.
- Игры: честность через печати/перепроигрывание (сервер слеп): морской бой —
  sha256 флота, «Сталкер» — перепроигрывание пути.
- Музыка: личные плейлисты — шифротекст на ключе музыки, сервер слеп; статус
  «слушает» — только память сервера (TTL 45 с); якорь только для публичного
  плейлиста или Диска; находки поиска сервером не хранятся.
- Смайлы (108): картинки смайлов — публичные файлы, личных данных не несут;
  маршрут `/api/emoji/` открытый, но принимает ТОЛЬКО образец кода смайла.
- База: файл `db.json`, фоновая волна записи `FILE_FLUSH_BG=1`; при аварийном
  обесточивании может потеряться до ~1,2 с изменений — честная граница.
- Мобильные правила (108, не ломать): клавиатура убирается ТОЛЬКО касанием
  свободного места; шторка чатов закрывается крестиком, касанием справа и
  смахиванием влево; плашка под сообщением всегда поднимается в видимую часть
  ленты.
