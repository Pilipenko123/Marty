# PILPRO — публикация на REG.RU

Это статическая страница: сборка, Node.js, база данных и установка пакетов не нужны. Для загрузки подготовлен архив `pilpro-site-upload.zip` (если он выдан отдельно). Внутри — `index.html` и папка `assets` с файлами стилей, скрипта и изображения.

## До загрузки

1. Проверьте страницу в Live Preview или локально. Локальный запуск из папки сайта: `python3 -m http.server 8000`, затем `http://localhost:8000`.
2. Войдите в личный кабинет REG.RU и откройте панель управления услугой **хостинга**. Для обычного веб-хостинга REG.RU указывает ISPmanager; названия разделов могут отличаться в зависимости от панели и тарифа.
3. Найдите домен `pilpro.ru` и его корневую папку сайта. Не угадывайте путь: REG.RU показывает корень сайта в панели, так как он зависит от настроек домена. В ISPmanager это раздел **Сайты**; в инструкции REG.RU для загрузки файлов предлагается открыть домен и выбрать **Файлы сайта**.
4. До замены скачайте резервную копию текущего `index.html` и папки `assets` (или всей корневой папки), чтобы можно было откатиться.

## Загрузить сайт через файловый менеджер

1. В файловом менеджере откройте именно корень `pilpro.ru`, найденный на предыдущем шаге.
2. Загрузите `pilpro-site-upload.zip` и распакуйте его в этом корне.
3. Проверьте структуру после распаковки:

   ```text
   index.html
   assets/
     pilpro-site.css
     pilpro-site.js
     pilpro-hero.jpg
   ```

   `index.html` должен лежать прямо в корне сайта, а не во вложенной папке архива. Существующие файлы перед заменой сохраните. Не удаляйте прочие файлы из `assets`, если не уверены, что они больше не нужны.
4. Откройте `https://pilpro.ru` в приватном окне или сделайте жёсткое обновление страницы (`Ctrl+F5` / `Cmd+Shift+R`). Проверьте мобильную версию, раскрытие услуг и ссылки на Segachat.

Альтернатива — загрузить те же файлы через FTP/SFTP в корневую папку домена. REG.RU публикует инструкции по определению корня сайта и загрузке через FTP в своей базе знаний.

## Важно для Segachat

Для этого способа публикации DNS менять не нужно. Не редактируйте и не удаляйте запись для `segachat.pilpro.ru`: чат остаётся на своём поддомене. Загружаются только файлы основного сайта `pilpro.ru`.

## Форма заявки сейчас

Форма подготавливает сообщение, открывает `https://segachat.pilpro.ru/` и копирует текст заявки. Посетитель вставляет его в чат и нажимает «Отправить». Сайт не сохраняет и не отправляет контакты сам.

У текущего Segachat нет публичного входящего API для анонимных заявок; его API рассчитан на авторизованных пользователей и зашифрованные сообщения. Поэтому автоматическую отправку без изменений чата или отдельного согласованного endpoint сделать безопасно нельзя. Папка `sega-chat` и сам чат при работе над сайтом не менялись.

## Что можно добавить позже

- Ссылку на портфолио — раздел уже подготовлен, сейчас предлагает запросить подборку работ.
- Телефон и/или e-mail — если хотите показывать их рядом с Segachat.
- Отдельную автоматическую интеграцию заявок — только если решите согласовать endpoint для Segachat в отдельной работе.
