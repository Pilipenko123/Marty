# SEGA-CHAT · помощник синхронизации папок

> **Статус: этапы 1–5 разработки готовы, этап 6 (приёмка владельцем) впереди.**
> Помощник скачивается из чата («Папка с ПК»), подключается разовым кодом и
> работает в фоне Windows при закрытом чате и заблокированном экране. Проверка
> на настоящих компьютерах и дисках владельца ещё не выполнена.

## Согласовано с владельцем 12.11.2026

- Одна выбранная папка на **трёх компьютерах владельца** должна содержать одни
  и те же файлы.
- Отдельной папкой можно поделиться с **компьютером друга**. Доступ друга не
  открывает остальные папки владельца.
- Дополнительно можно связать папку с **выбранными папками Яндекс.Диска и
  Google Диска**. Весь диск автоматически не копируется.
- Обмен идёт, когда компьютер включён и есть сеть, **без открытого чата и при
  заблокированном экране**. Для этого нужен помощник Windows, а не вкладка
  браузера.
- Помощник скачивается из чата; инструкция по установке находится там же.
- Новые и изменённые файлы копируются автоматически. Если файл изменён на двух
  компьютерах, сохраняются **обе версии**. Удаления и спорные замены требуют
  отдельного подтверждения.

## Этапы всей задачи

Процент считается от всей задачи, а не от текущего файла.

| Этап | Доля | Накопительно | Результат |
| --- | ---: | ---: | --- |
| 1. Правила и ядро защиты файлов | 15% | 15% | Пути, версии, конфликты, подтверждения, атомарная запись; тесты |
| 2. Помощник Windows и обмен между ПК | 25% | 40% | Фоновый агент, зашифрованная очередь, куски, подтверждения из чата |
| 3. Доступ компьютеру друга | 15% | 55% | Приглашение, права чтение/изменение, отзыв и обновление ключа |
| 4. Выбранные папки Яндекс/Google | 20% | 75% | Облачные мосты без передачи токенов помощнику |
| 5. Окно в чате и установщик | 15% | 90% | Кнопка скачивания, код, инструкция, автозапуск, удаление |
| 6. Приёмка владельцем | 10% | 100% | Проверка на трёх Windows-ПК, дисках и друге; исправления по итогам |

## Что где лежит

| Файл | Назначение |
| --- | --- |
| `core.js` | Пути, версии, конфликты, AES-256-GCM события/куски/состояние, ключи P-256 и свёртки |
| `local.js` | Локальная папка: журнал вне папки, атомарная запись, backups/trash, подтверждения |
| `agent.js` | Фоновый помощник: подключение, очередь, куски, команды, статус, автозапуск |
| `cloud.js` | Мост выбранных папок Яндекс/Google: список, скачивание, загрузка, удаления с подтверждением |
| `vault.js` | Секреты помощника: Windows DPAPI текущего пользователя; вне Windows — файл 0600 для тестов |
| `install.cmd` / `install.ps1` | Установка без администратора: Node.js при необходимости, папка, код, автозапуск |
| `uninstall.cmd` / `uninstall.ps1` | Убирает автозапуск и останавливает помощник; файлы и служебные копии остаются |

## Как подключить компьютер

1. В чате откройте «Папка с ПК» → «Код для этого ПК».
2. Скачайте архив помощника, распакуйте, запустите `install.cmd`.
3. Выберите синхронизируемую папку, вставьте код, задайте имя компьютера.
4. Вернитесь в чат и создайте папку синхронизации для этого компьютера.
5. На втором и третьем ПК повторите установку, затем добавьте их кнопкой «Добавить ПК».
6. Для друга: «Поделиться с другом» → участник общего чата → право чтение/изменение.
   Друг принимает приглашение на своём ПК.
7. Для облака: «Подключить папку диска» → выберите конкретную папку Яндекс/Google.

## Правила безопасности файлов

- Путь канонический: без `..`, дисков, UNC, потоков NTFS, служебных имён Windows,
  управляющих символов и имён с пробелом/точкой в конце. Unicode приводится к NFC.
- Решение принимает журнал версий (SHA-256), а не «у кого дата новее».
- Новый файл создаётся атомарно: временный файл → сумма → fsync → жёсткая ссылка
  без замены (на FAT/exFAT — копирование без замены).
- Неизменённый локальный файл обновляется; прежняя версия сохраняется в `backups/`.
- Одновременная правка даёт конфликт: оригинал не затирается, пришедшая версия
  сохраняется как `имя (конфликт <ПК> <событие>).ext`.
- Удаление сначала попадает в запрос подтверждения. После подтверждения файл
  уходит в `trash/<запрос>/`, а не в небытие. Изменившийся файл не удаляется.
- Локальное удаление файла, который есть в журнале, тоже ждёт подтверждения.
- Восстановление файла, удалённого локально без подтверждения, ждёт подтверждения.
- Символические ссылки и точки соединения не обходятся; коллизии регистра останавливают проход.
- Служебные файлы (`.git`, `node_modules`, `~$*`, `*.tmp`, `*.part`, `.crdownload` и др.) пропускаются.

## Криптография и сервер

- Ключ папки — 32 случайных байта; сервер его не получает.
- Событие: AES-256-GCM, AAD = канонический контекст `{v, folderId, eventId, deviceId, op, keyRev, pathHash}`.
  Имя файла серверу не показывается даже в контексте — только SHA-256 пути.
- Файл режется на куски по 512 КиБ; каждый кусок — отдельный AES-256-GCM конверт
  с AAD `sega-sync-chunk-v1|folderId|eventId|index`.
- Состояние помощника (пауза, ошибки, запросы подтверждения) шифруется ключом папки.
- Каждый компьютер имеет пару P-256. Ключ папки сворачивается ECDH + AES-256-GCM
  ровно в 60 байт для каждого компьютера и участника.
- Пропуск компьютера (`sd_…`) хранится на сервере только как SHA-256; отзыв
  компьютера или друга останавливает очередь и требует обновления ключа папки.
- Очередь ограничена: по умолчанию 128 МБ на компьютер, 256 МБ на папку, 512 МБ
  всего, файл до 128 МБ, срок хранения 7 суток. Куски удаляются после получения
  всеми адресатами, при отзыве, очистке папки и по сроку.
- Облачные мосты работают только на компьютере владельца. Токены Яндекс/Google
  остаются на сервере; помощник получает адрес одного действия и ходит по нему
  потоком. Весь диск не копируется — только выбранная папка.

## Ограничения и честные границы

- Это разработка этапов 1–5. Приёмка на настоящих Windows-ПК, Яндекс/Google
  Дисках и компьютере друга ещё не выполнена.
- Помощник требует Node.js 18+; установщик при отсутствии скачивает официальный
  переносимый Node.js 22 x64 и проверяет SHA-256.
- Автозапуск — папка Startup текущего пользователя, без службы и администратора.
  При заблокированном экране процесс продолжает работать; при выключенном или
  спящем ПК обмен ждёт включения/пробуждения и догоняет изменения.
- Вне Windows секреты хранятся файлом 0600 только для разработческих проверок.
- Облачные документы Google (Docs/Sheets/Slides) не экспортируются мостом как
  обычные файлы; синхронизируются файлы с байтами.
- Одна папка на компьютер; до 20 папок на участника; до 6 облачных папок у одной
  папки ПК; до 12 подключённых компьютеров на участника.
