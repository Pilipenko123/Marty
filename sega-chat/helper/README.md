# SEGA-CHAT · помощник синхронизации папок

> **Статус: этап 1 из 6, в разработке. Это ещё НЕ установщик для владельца.**
> Здесь живут ядро помощника и его правила. Кнопка скачивания, подключение
> компьютеров и обмен появятся на следующих этапах. Существующий мессенджер и
> облачные диски этим этапом не меняются.

## Согласовано с владельцем 12.11.2026

- Одна выбранная папка на **трёх компьютерах владельца** должна содержать одни
  и те же файлы.
- Отдельной папкой можно поделиться с **компьютером друга**. Доступ друга не
  открывает остальные папки владельца.
- Дополнительно можно связать папку с **выбранными папками Яндекс.Диска и
  Google Диска**. Весь диск автоматически не копируется.
- Обмен идёт, когда компьютер включён и есть сеть, **без открытого чата и при
  заблокированном экране**. Для этого нужен помощник Windows, а не вкладка
  браузера.
- Помощник скачивается из чата; инструкция по установке находится там же.
- Новые и изменённые файлы копируются автоматически. Если файл изменён на двух
  компьютерах, сохраняются **обе версии**. Удаления и спорные замены требуют
  отдельного подтверждения.

## Этапы всей задачи

Процент считается от всей задачи, а не от текущего файла.

| Этап | Доля | Накопительно | Результат |
| --- | ---: | ---: | --- |
| 1. Правила и ядро защиты файлов | 15% | 15% | Пути, версии, конфликты, подтверждения, атомарная запись; тесты |
| 2. Помощник Windows и обмен между ПК | 25% | 40% | Фоновая работа, подключение трёх ПК, шифрованная очередь, докачка |
| 3. Доступ другу | 15% | 55% | Отдельная папка, выбранный компьютер друга, отзыв доступа |
| 4. Мосты Яндекс/Google | 20% | 75% | Выбранные папки дисков, страницы, потоковая передача, ограничения прав |
| 5. Окно в чате и установщик | 15% | 90% | Скачивание, инструкция, состояние компьютеров, подтверждения |
| 6. Приёмочные проверки и выпуск | 10% | 100% | Полный набор тестов, стенды отказов, проверка Windows 10 владельцем |

«100% разработки» не означает, что программа уже проверена на настоящих
компьютерах владельца. До такой проверки граница называется прямо.

## Архитектура

```text
Папка ПК 1 ─┐
Папка ПК 2 ─┼─ помощники Windows ─ зашифрованная очередь SEGA-CHAT ─ помощник ПК 3
Папка ПК 3 ─┘                         │
                                      ├─ выбранные папки Яндекс.Диска
                                      └─ выбранные папки Google Диска

Отдельное разрешение ─ помощник друга ─ только разрешённая папка
```

### Что видит сервер

- Между компьютерами передаются **зашифрованные версии файлов**. Ключ папки
  создаётся на устройстве владельца и открывается только разрешённым
  помощникам. Сервер хранит очередь, сроки и получателей, но не открытое
  содержимое файлов и не ключ папки.
- Подключение помощника — разовый код из чата. После подключения у компьютера
  собственный отзываемый пропуск; код повторно не работает.
- Очередь имеет предел места и срока. Большой файл передаётся кусками и не
  загружается целиком в память VPS. Получатель подтверждает приём; пока
  подтверждения нет, событие не считается доставленным.
- Облачный мост — отдельное разрешение на конкретную папку. Файлы на
  Яндекс/Google остаются у соответствующего провайдера с его обычными правами.
  Мост не должен получать доступ ко всему диску только ради одной папки.

### Что помощник делает на компьютере

- Работает от имени вошедшего пользователя Windows. Заблокированный экран ему
  не мешает: процесс продолжает работать после входа в Windows.
- Автозапуск регистрируется на вход пользователя. Выключенный компьютер, спящий
  режим без разрешённого пробуждения и отсутствие сети обмен не выполняют;
  накопленные изменения догоняются позже.
- Следит за выбранной папкой и дополнительно сверяет её по расписанию: событие
  наблюдателя может потеряться, поэтому оно не единственное доказательство изменения.
- Хранит журнал принятых версий отдельно от синхронизируемой папки. Повторная
  доставка того же события не создаёт второй файл.
- Пишет через временный файл и проверяет контрольную сумму. Перед заменой
  сохраняет прежнюю версию в служебной папке помощника.
- Не следует символическим ссылкам и точкам соединения Windows наружу выбранной
  папки. Служебные и временные файлы офисных программ и браузеров по умолчанию
  пропускаются.

## Правила решений

Они проверяются тестами, а не только записаны в инструкции.

| Что пришло | Что на диске | Решение |
| --- | --- | --- |
| Новый файл | Файла нет | Создать |
| Та же контрольная сумма | Тот же файл | Ничего не копировать |
| Новая версия | Локальная версия не менялась с последней синхронизации | Обновить, сохранив прежнюю копию |
| Новая версия | Локальный файл тоже изменён | Сохранить обе версии: исходное имя не занимает копия |
| Новая версия | Нет журнала, а локальный файл отличается | Спорная замена: сохранить обе версии, не угадывать по дате |
| Удаление | Файл есть | Записать запрос на подтверждение; **не удалять** |
| Повтор события | Уже принято | Пропустить |
| Опасный путь (`..`, диск, поток Windows, ссылка наружу) | Любое состояние | Отказаться до записи |

Дата изменения файла используется для показа человеку, но **не решает**, чья
версия главнее. Основание для автоматической замены — совпадение локальной
контрольной суммы с последней синхронизированной версией.

## Границы первого этапа

Сделано: правила, разбор путей, планировщик решений, шифрование событий,
локальный журнал, атомарная запись, конфликтные копии, запросы на удаление и
подтверждаемое удаление с сохранением служебной копии. Проверяется тестами Node.

Ещё не сделано: сетевой обмен, фоновая служба Windows, скачивание из чата,
доступ другу и облачные мосты. Не называть этот этап готовой синхронизацией.

На NTFS создание файла идёт через жёсткую ссылку без замены существующего имени.
Если файловая система не умеет жёсткие ссылки (например, некоторые FAT/exFAT или
сетевые папки), запасной путь копирует проверенный временный файл с запретом
перезаписи; на таких папках атомарность появления имени слабее, и это будет
показано владельцу при подключении.

## Запуск проверок

Из `sega-chat/`:

```text
node test/sync-core.mjs
```

Полная проверка проекта перед выпуском:

```text
npm install
npm test
```

Новых библиотек нет. Ядро использует только встроенные модули Node.
